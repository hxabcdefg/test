# Aurora Lab 网页改版

这是一个纯静态的高质感产品官网页面示例，包含完整的首屏、体验模式切换、能力说明、数据证明、升级流程和 CTA 转化区域。

## 本地预览

直接在浏览器中打开 `index.html` 即可预览页面。

如果希望通过本地服务预览，可以运行：

```bash
python3 -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

## 设计升级点

- 深色高级视觉系统：渐变光效、磨砂玻璃卡片、柔和阴影和网格背景。
- 更完整的信息架构：首屏价值、体验模式、设计能力、结果证明、升级流程、最终转化。
- 模式切换交互：品牌沉浸、增长转化、服务说明三种内容模式。
- 响应式布局：适配桌面端、平板和手机端阅读节奏。
- 轻量动效：鼠标光晕、卡片悬浮、数据滚动动画，增强页面完成度。
